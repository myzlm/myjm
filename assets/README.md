# 器物

店里所有的图都在这里，按「人」「景」「杂件」分三个夹子。

```
assets/
├── characters/   人
│   ├── ai.png      艾（柜台后面那个人）
│   └── doll.png    纸人、贴脸、墙后那张脸
├── scenes/       景
│   └── cover.png   封面（1024×1536）
└── ui/           杂件：图标、纹理、印章
```

## 往里放东西

- **同名替换就好**：想换艾的脸，直接把 `characters/ai.png` 覆盖掉，别的地方不用动。
- **加了新人**：按 `characters/<名字>.png` 放，场景按 `scenes/<场景>.png` 放。
- **人像要透明底**，高度 800 像素以上，界面会自己缩放。
- **单张别超过 2MB**。双击打开时是从本地读的，不联网，但太大还是会卡。
- **别放音频**。声音不在这儿——它们是现场生成的，没有文件。

## 没有图也不会坏

柜台、门、抽屉、长明灯、水碗、纸钱、纸人、卷轴，全都是画出来的。

删掉任意一张图，甚至清空整个 `assets/`，游戏照样能从头走到尾——只是少了一点颜色。

图是锦上添花，不是骨架。

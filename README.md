# 代码之下

> 你收到一封没有寄件人的邮件。
> 附件是一个游戏，说明只有一句：请在一小时内装好。
>
> 装好之后，你在里面看见了自己。

一部关于记忆、抵押与「第三十六次」的长篇交互小说。六章正文，九张进门的票根，一间可以摸的屋子，三十五位前任留下的东西，最后一班七位客人与九格油，二十二种结局；柜台底下还压着一只木箱，六件别人没做完的活；以及一本不写别人、只写你的册子。

<https://github.com/myzlm/myjm>

---

## 这是一间什么样的店

店没有名字，门牌上只有一个烧掉一半的字。

柜台后面坐着一个叫**艾**的老人。他收的不是钱，是记忆：你押下一段记忆，他给你一把钥匙，钥匙能开柜台后面那扇门。门后是什么，取决于你押下的东西有多清楚，也取决于你当面拆穿了他几句话。

这里的规矩是——**登记是给活人看的，抵押是给这边看的。**

三十五个名字被划掉了。你是第三十六个。

## 开始

双击 `index.html` 就行。不用安装，不用配置，也不用起服务器。

除了「记忆核验」那一步会试着去查一下你说的事——查不到就自己判断，不耽误你往下走。

第一次点击会解锁声音，`M` 静音。关灯，戴耳机。

进度会自己记住：每一章开头留一张票，关掉页面再打开，它问你接着走还是重开一间（见下面「关掉页面以后」）。想从头再来，点「重新开一间」；想连收藏一起清，清掉这个站点的本地数据即可。

| 键 | 用处 |
|---|---|
| `G` | 屋子 —— 整间店摊成一张图，想去哪儿点哪儿 |
| `P` | 代码透视 —— 让这间屋子半透明 |
| `K` | 墨韵 · 科技卷轴 |
| `L` | 里间 —— 柜台后面那道缝 |
| `D` | 对局 —— 让他出题，你答 |
| `V` | 档案册 —— 你还剩多少没看见 |
| `Y` | 柜台底下的木箱 —— 六件手上的活 |
| `Q` | 打烊以后：出门，走那条街（第七章） |
| `J` | 证物册 —— 进了第二章才有用 |
| `B` | 弹幕 |
| `F2` | 终端 —— 长得像开发者工具的那个 |
| `M` | 静音 |
| `Esc` | 关掉眼前这一层；没有浮窗时＝先放着，退回上一步 |

### 要玩多久

| 走到哪儿 | 大概 |
|---|---|
| 五章主线，谜题全解 | 一小时上下 |
| 第六章：七位客人，每人问对一句、写一行，九格油怎么分，改判一次，结算七段后日谈 | 一小时到两小时 |
| 里间：三十五个人读完、三个视角、一次错位、六个人的话 | 两小时上下 |
| 墙上的剪报：十二页看清，算一算那些年 | 半小时到一小时 |
| 对局赢满七局（题只从你读过的人里出） | 半小时到一小时 |
| 木箱里那六件活：修好、读完补记、再决定放哪儿 | 半小时上下 |
| 第七章：五个门、三个姿态、街尽头那一下 | 二十分钟上下 |
| 二十二个结局逐一走到，再翻开柜台底下那本册子（含二周目与编辑器里那几条捷径） | 合计七小时以上 |

它不是靠重复刷时长。是三十五段别人的人生摆在那儿，一段一段，你舍不舍得读完。

### 九张票根

每一章进门之前，柜台给你一张票。

票上印着第几章、叫什么，两行题记，右下角压一枚章——`入`、`录`、`押`、`证`、`薄`、`根`、`当`、`外`、`回`。盖完才放你进去。点一下或者按任意键可以催它走，三秒它也自己走。

同一章第二遍进来，票只晃一下——仪式是给第一次的。

九张票收在档案册的「票根」页签里，翻过来能看见它借的是谁的胆子：

| 票 | 借的 |
|---|---|
| 序章 | 《Pony Island》——游戏本身是一扇门，不是一段内容 |
| 第一章 | 《The Stanley Parable》——选择都是被摆好的 |
| 第二章 | 《The Beginner's Guide》——讲述的和看见的不是一回事 |
| 第三章 | 《Return of the Obra Dinn》——证词要拿东西对上去 |
| 第四章 | 《Superliminal》与《P.T.》——走廊会自己重排 |
| 第五章 | 《Undertale》与《DDLC》——存档、删档也是叙事 |
| 第六章 | 《Papers, Please》——一支笔，和一条不许全都放过的规矩 |
| 第七章 | 《Kentucky Route Zero》与《That Dragon, Cancer》——一条街只给一束光，后果不在纸上 |
| 终章 | 《NieR: Automata》——结局是你做过的事的形状 |

### 关掉页面以后

柜台会替你留一张「上次的门票」。下次打开，它先问你两件事：接着走，还是重新开一间。

接着走，是从那一章的开头重新站定——钥匙、物证、办过几笔、见过几个结局都在，但不会把你丢回半句话中间。存档六秒落一次，切走页面也会落。走到结局，票就收回去。

彩蛋、结局、票根这些收藏，重开一间也不清。

## 序章 · 登录地球online

下载页的「安装并运行」后面不是大厅，是一张很旧的登录框。

- 服务器只有一台：**记忆殿-01**，延迟 `—`，在线 `1`
- 账号固定为 **访客 036**；访客通道是关的
- 口令写在邮件正文里，是 36 的八位二进制

输错三次，屏幕上会多出一行不属于你的字。

输对之后是五段加载：连接、握手、验证记忆锚点、加载典当行、穿透。加载条下面浮着三炷香，烧得比加载条快。

## 第一章 · 邮件

### 一封邮件

收件人是你，寄件人一栏是空的。正文很短，附件叫 `game`。

下载到 62.5% 的时候，「Windows 安全」会闪一下——一闪而过，快到你可以当自己看错。

### 记忆殿

系统未响应、重启，然后你站在一座殿里。殿上有三个字：代码之下。下面一行小字：第 36 个。两个按钮：**离开**、**前往**。

选「离开」，殿会抽搐，绿光转红，代码流提速，程序未响应，重启——回来的时候，「离开」不见了。它已经不在选项里了。

选「前往」，是一段机械和声的欢迎，一张桌子，一份合同。有人影把合同拿起来又消失，然后是瞬移贴脸：头和身体是分开的。

合同要填四样：名称、性别、职业、长按录指纹。交还之后你会发现——名字被划掉了，旁边一个红笔写的「三十六」，性别那一栏消失了。

接着是二十秒黑暗。这二十秒里点什么都不会发生（点满一百下会有一个成就，叫「急也没用」）。

黑暗结束，一张洋娃娃的脸贴上来，然后你坐在柜台前。

### 柜台

左手边是柜子，右手边是电脑桌。机箱坏了，得你自己修：

- 拍机箱 → 跟着重音敲键盘。容差半秒；职业填了跟音乐有关的，容差收紧到 0.3 秒——不是放宽，是耳朵比手快。
- 撬棍 → 四个角，每个角八十到一百二十下才松。可以按住不放，它会自己连撬。
- 撬到一半，洋娃娃递来一张纸，上面的字在「快走 / 不要回头」和「救救我」之间来回换。
- 撬机箱的界面上有一个很小的位置。连着点到它三次，会花屏，浮出一双眼睛，问你：「你是不小心的吧？」

### 紫光

电脑好了，屏幕上要密码。密码是随机的，七到二十六位，你不知道是什么。

柜子里有一支紫光灯。照到键盘上，只看得见几个键上留着指纹，每个键写着一个数字——**这个数字，是这个键在密码里所有「从右数位置」的和**。

比如密码是 `asdffas`（七位），从右往左数：s=1、a=2、f=3、f=4、d=5、s=6、a=7。于是

```
a → 7 + 2 = 9
s → 6 + 1 = 7
d → 5
f → 4 + 3 = 7
```

紫光下就只有 a=9、s=7、d=5、f=7 四个键亮着，便签上写着「密码 7 位」。

打开紫光以后，每个键底部是它该有的数，顶部是你按出来的数。超了变红，对上了变绿——二十六位也能像调音一样一点点拧回去。输错不清空，退格改就行。

进去是 Windows 98。桌面上有一个以你名字命名的文件夹，里面一个 PDF。右键，打印，打印机吐纸，你把纸交给老人。

## 第二章 · 抵押

交纸不是结束。艾收下那张纸之后才把规矩说清楚：**登记是给活人看的，抵押是给这边看的。**

柜台上多了一张空白抵押单。填上你要押的东西，店才开始真正收你。

### 抽屉里的三样东西

柜台下面有一个抽屉，锁不是数字，是账。

| 谜题 | 玩法 | 难在哪儿 |
|---|---|---|
| **账本** | 三行旧账各缺一个钥匙品级；页脚三条线索（「齿最浅的是谁」「三十二号比三十一号值钱」）。每格点击循环：？→ 残破 → 普通 → 完美 | 逻辑推理，只有一个解 |
| **记忆胶片** | 八段被剪散的童年记忆，点两段交换位置，接回原来的顺序。只报「已经接对 3/8」，不报哪儿对 | 叙事排序，读得懂就排得出 |
| **愿望天平** | 选一个愿望押掉，换一顿吃的。用 1 / 2 / 4 / 8 / 16 五块砝码把秤配平，秤盘随差值倾斜 | 凑数不难，难在你舍不得 |

天平上，愿望越大，菜越好，也越舍不得。

### 钥匙的品级

胶片每错一次——接错，或者你点了「让他念一遍」求提示——记忆就少一点细节。细节八分对应**完美**，七分六分是**精良**，五分四分**普通**，三分**残破**。

这是艾说的那句「您说得越清楚，我就记得越牢」。

钥匙的品级不改通关与否，只改门后你看见什么。

### 另外三样东西

抽屉开过之后，柜台上还有三样东西能动。它们不挡路，解不解都行——但解了，钥匙会好一档。

| 东西 | 怎么玩 | 会错在哪儿 |
|---|---|---|
| **长明灯的油** | 三只碗，八钱、五钱、三钱。点一只，再点另一只，油自己流过去，流到满或流干为止。要在两只碗里各量出四钱 | 七步就能到。但你多半会先把它倒成一锅粥——倒错了不罚，重来就是 |
| **墙上的钟** | 钟背刻着两个字：**三**、**未过半**。记录卡最后一行是 `expire 今夜 03:14`。把钟拨到那一刻 | 钟停在十点十分。多数人会顺手拨到「下午三点十四」——那是错的。未过半，是凌晨 |
| **地板上的刻痕** | 六组刻痕，深的一道、浅的一线，四道一组。深算一，浅算零，读成六个数 | 深的是「一」不是「零」，四道一组不是三道。答错它会告诉你第几组错——只告诉一组 |

三样都能重来，都有四级提示，不限次数。

油倒对了，灯自己亮起来；钟对上了，钥匙是**完美**；刻痕六个数字对了，地板会翘起一块——下面是一枚铜片，三十六道划痕，和一道新的。

### 开门之前

门缝里有人叫你的名字，一共六声。

规矩只有一条，得自己从文本里读出来：**活人叫人，脚步声先到；没有脚的东西，只有声音，永远等不到脚步。**

前五声，只有声音，然后是一片安静。不能应。应了，门缝底下就多一道影子。

第六声，先是一双布鞋蹭地的声音，走了很久才停在门口，然后是母亲的声音说「出来吧，妈在这儿」——**这一声要应。**

一声不差，门外没有人，只有一把伞靠在门框上。伞面上补过一块，针脚很密。

## 第三章 · 他说的话

这一章的规矩很简单：**艾说的每句话，都能在店里找到反证。**

一处也不拆穿，照样能走到门口——只是门后是什么，会不一样。

### 店里的东西

柜台上添了几样东西，第一章就能点，进了第二章才变成「物证」。

| 物件 | 是什么 | 由来 |
|---|---|---|
| 长明灯 | 豆大的火，没有风也在偏 | 停灵不灭的灯。灯灭了不是等客，是等客留下 |
| 水碗立筷 | 半碗水，筷子立在水中不倒 | 乡下问鬼的法子：筷子立住，就是旁边站着人 |
| 一叠黄纸 | 剪成铜钱的找零 | 冥币。纸钱是「寄」的，寄给谁，谁就已经不在这一头了 |
| 黄历 | 停在一页：七月十五，宜祭祀，忌出行、夜哭。整本圈到纸破，页脚印着「今日值日：牛头、马面」 | 中元，鬼门开 |
| 柜台底下 | 蹲下去看：灰上有两道拖痕，一个躺着的宽度，从门口一直拖到柜台后面 | —— |

### 六件物证，六句谎

每件物证都对着他说过的一句话。凑齐了，点他，菜单里会多出一条「（摆出：××）您刚才那句，不对。」

| 他的话 | 反证 | 被问住之后 |
|---|---|---|
| 这店里只有一扇门。我没出去过。 | 柜台腿下压着一张 1998 年的长途汽车票，青石桥 → 柳河集（你老家那个乡） | 「捡的。柜台上什么都会掉下来。」 |
| 抵押了就不疼，只是空出来一块。 | 账本撕掉的残页：「押后第七日，仍夜夜起身，至门口，呼一名。」 | 「那是别人。账上写的，不一定是我记的。」 |
| 记忆越细，钥匙越好。 | 账本页脚另一种笔迹：「齿深者，锁不住。太细的东西认主；认了主，就自己开门走了。」下面还有一行：别跟客人说 | 「这句不是我写的。这本账，前面换过七个人。」 |
| 抽屉里三十五个名字，都被划掉了。 | 黄历被圈破的那一天：七月十五。圈了三十五次 | 「圈的是我自己的日子。」 |
| 您没说过名字，我也没问。 | 一张纸钱上写着「寄：（你的名字）收」，是你的笔迹 | 「您进门的时候，报过名字。」——你只报了姓。 |
| 我是这里的掌柜。 | 柜台内侧刀刻：「艾。民国廿六年。押。」后面两个字：第一。磨掉的那个字是「身」 | 「掌柜的，也得有个名分。」 |

六条全拆穿，菜单顶上会多出一条金色的：「（把六件东西全排在柜台上）还有一句话您没说。」

他会告诉你：三十六个不是三十六个人，是三十六次；账本上从来只有一个名字，写了三十五遍。

### 门后

| 拆穿了几处 | 门后 |
|---|---|
| 0—2 | 按钥匙品级：一条走廊 / 一片白 / 门没有动 / 门后有指甲刮木头 |
| 3—4 | 走廊还在，尽头那个空脸的人说：「你上次也问了这句。」 |
| 5—6 | 门后不是走廊，是柜台。柜台后面坐着一个人，那张脸是你的脸，比你老很多。他说：「我等你，等了三十五次。」<br>他走出去，你坐下。账本第三十六行的押品栏写着：**身**。 |

## 第四章 · 渲染层

开了门以后不是走廊，是一条**走廊的正面**。这里所有的东西都是画上去的，侧面零像素。

### 一堵比人薄的墙

前面「站着一个人」，你只看得见墙。

按 `Tab` 调出检查器，五行元素排在那儿，各自的层级写得清清楚楚。把墙降到人后面，或者把人提到墙上面，墙就薄下去了——后面站着掌柜，正面朝你。

点他，他会转到侧面，然后消失成一条线。他没有背面。人是需要背面的。

### 两帧之间的东西

灯灭了。有什么东西开始跟着你，**它只在两帧之间移动**：平时不显示；你一按 `P` 打个断点，世界停在某一帧，它才显出线框，你也才看得见它离你多近。

- 走廊八格。你每走一步要 0.5 秒，按快了没用。它每 0.45 秒挪一格。
- 断点只有三次，每次 1.6 秒。断点里它不动，你能走。
- 被追上就是半秒突脸加全屏红闪，走廊重来——它记得你走到哪儿。

### 一扇没有 onclick 的门

走廊尽头有一扇门，没有把手。点它没反应——因为它没绑过任何东西，它只是一个方块。

等几秒，右下角会亮起 `</>  F2`。打开终端，让那扇门开：

```
open #ly-door3
```

艾在很远的地方说：「您不该学会这个。」

从这里开始，写权限交到你手上。

## 第五章 · 根目录

门后是往下的。不是楼梯，是往下滚动的行。

### 三十七行

记录库里有三十七行，每行一个人：编号、名字、押品、状态。列表自己往下跑，二十五秒后还会变快。

只有一行是 `#036  ████  身  待覆盖`。其余全是「已释放」。

点错三次，会有一张脸闪出来。

### 七个假的

这三十七行里有七行不是记录，是**留白**。混在一起，只有仔细看才分得出：

- 两个记录同名同姓
- 押品是「身」的，状态却是「已释放」
- 日期比上一行还早
- 编号那一格是空的
- 你的名字出现在别人那一行里
- 状态写着「第一次来」——那是日志里的话，不是状态
- 什么都没押，也是「已释放」

挑错了它会告诉你：有几行是冤枉的，还漏了几行。七行全挑出来，它们同时变灰，像被抽走，底下浮出三行注释：

```
// 记录不是被写进来的。是被留出来的。
// 谁把名字留在这儿，谁的那一行就会一直跑。
// 三十七不是上限。是这一版列表的长度。
```

### 你的那一行

```
{ "id": 36, "name": "████", "collateral": "身", "state": "待覆盖",
  "visits": 35, "expire": "今夜 03:14",
  "note": "前 34 次都选了「退出」。第 35 次，他自己走到了 /var/records。" }
```

### 四个键

| 键 | 结果 |
|---|---|
| **覆盖** | 你坐进柜台。下一封信已经发出去了。柜台内侧的刻字多了一行：你。今夜。押。第三十六。 |
| **删除** | 这一层往下塌，一行一行地消失，每消失一行有一声很轻的「谢谢」。最后只剩 `SIGTERM`，你坐在自己家的电脑前，键盘上有一层灰。 |
| **退出** | 记忆殿像标签一样被关掉。你醒在 02:14，那封信还开着。门响了，有人用指甲刮门，刮的位置刚好是坐着的人头的高度。 |
| **把那一行划掉** | 收齐四条代码线索才会出现。你删掉记忆殿里那一行注释，殿塌了，露出下面一台很旧的家用电脑。艾说：「我不是被关在这里的。我是自己写的这间店。」 |

## 第六章 · 收摊

四个键里无论按哪个，门都开了。但门后面不是外面，是柜台。

你走回去，柜台里没有人。台上压着一张纸：

> **今 日 当 班**
> 七位。油是你自己的，一共九格。
>
> 照实写——他保住，两格油从你身上出。
> 照规矩写——折他一半，一格。
> 照他说的写——他一笔不算，你一格不烧。
> 不收这一笔——你陪他耗三格，账上还倒扣。
>
> 七个人全保住，要十四格。
> 你只有九格。

字迹是新的。墨还没干。

这里没有正确答案。**这是一个必须有人受损的局。**

### 一笔账的两面

柜台底下有两样东西，一进一出：

- **油**是你的。一天九格，用一格少一格，用完灯就灭。
- **账**是从客人身上折出来的。账面越好看，人越难看。

同一个人，你越对他好，你自己的油烧得越快。你把七个人都保住，需要十四格——你没有那么多。

所以每一笔都要选：这一格油，救谁。

| 写法 | 你的油 | 账 | 他 |
|---|---|---|---|
| 照实写 | −2 格 | 0 | 保住 |
| 照规矩写 | −1 格 | +2 | 被折 |
| 照他说的写 | 0 | +3 | 作废 |
| 不收这一笔 | −3 格 | −2 | 没办 |

九格油，七个人。**最多救四个，而且救四个的时候灯一定是灭的。**
灯亮着，你只能救三个。

油不够的时候，那两条路是灰的，点不动——不是你不肯，是你没有。

### 掀开他的手

三句问话之外，还有一个动作：**掀开他按着的东西。**

他会让你看。你能看到他不想说的那些：收据背面的一行铅笔字、缴费单上最上面那张的方章、作文纸上只写了两百字的那一页、手机里一条自己写给自己的备忘。

代价是你自己的一格油。你看得越多，能救的人越少。

这条路上有个名字：掀开五次、救不到三个人，结算时他会说一句「你比我狠」——不是夸你。

### 划掉一行

第六位走了、第七位还没进来的那一小段，你可以回头把已经写好的六行**划掉一行重写**。

只这一次。改判不烧额外的油（按差价算），也收不回已经说出口的话——他记得原来的那一版。结算单上那一行会留一道划掉的印子。

大多数人不会改。改的是承认自己判错了。

### 第六条路

第六位押的是「一个还没取的名字」，换「忘掉」。

她有三条路：不收（她记住疼）、照他说的（她忘干净，连名字一起）、照规矩（折一半）。

还有第四条：**从你自己的抽屉里拿一件东西压上去。**

那是你从里间带出来的、别人留下的东西。压上去，她保住名字，也忘了疼。你少一件，想不起来是哪一件了。

抽屉里那格会空着，空得很整齐，像被人擦过。

七位走完，打烊之后有一张结算单：七笔逐条列着，**每一行都能点开**，看这一笔之后他的三年是怎么过的。底下有一行统计：保住几个、被折几个、作废几个、抵了几个。

### 七位

| # | 谁 | 押什么 | 想换什么 |
|---|---|---|---|
| 01 | 赵德海，五十六，钳工 | 一只右手（只剩两指） | 儿子下学期的学费 |
| 02 | 刘小燕，二十三，护工 | 睡眠 | 母亲一周三次的透析 |
| 03 | 一个穿校服的，十六 | 六月七号上午 | 让家里别再摔东西 |
| 04 | 周敬之，六十一，退休教师 | 一本教案，六册 | 见一个人一面 |
| 05 | 陈立，三十四，骑手 | 一条左膝 | 撤掉一个差评 |
| 06 | 一个抱襁褓的女人 | 一个还没取的名字 | 忘掉 |
| 07 | 最后一位 | 剩下这一天 | 交班 |

每个人都有一句问对了才会说的话。比如问赵德海「那台冲床，后来装护栏了吗」，他会告诉你护栏花了两千四——比他的手贵。问那个骑手「你有没有申诉过」，他会告诉你系统回了他三个字：已处理。

问不出来的人，你也能办。只是你办的是他说的那一版。

### 四种收摊

油决定了你怎么收这一班：

- **灯还亮着**：第二天门口进来一个人，很年轻，手里攥着一张纸。你说：哦——来了啊。别站着，坐。
- **灯灭在你手里**：你去拧灯芯，拧不动。柜台上的纸被风吹起来一张，又落回去。街上没人进来——灯灭了的店，没人进来。
- **一个都没作废**：七个人都还在纸上。你救了几个，折了几个，但没有一条被划掉。（长夜）
- **让了位**：第七位只有一个要求——你坐这儿，还是我坐这儿。你把位置给他，门在你身后合上。手里一张纸，写着今天的日期，和七个名字。

## 第七章 · 门外

打烊之后你从店里走出去。天没亮透，街上有雾，早点摊刚支起来。

手里那张纸上有七个名字，每个名字后面跟着你昨晚写下的那个词。街上有五个门，门后面是其中五个人——**你写下去的那一笔，已经落到他们身上了**。

你在柜台后面看不见这件事：你只看见纸。写的时候「被折了」是一个词，走出来才看清它是一天。

这一章不给选项，给三个姿态：**走近**、**说一句**、**走开**。每站只能用一次。

- **走近**：看清一点。多半是一个数字，或者一处旧伤。
- **说一句**：你说的那句话，取决于昨晚你是怎么写的——照实写、照规矩写、照他说的写、不收这一笔。四种人，四句话。
- **走开**：不打扰。有些人你只能不打扰。

你说什么他们都不会因此好起来。判决在昨晚就生效了，这条街只是让你看见它生效的样子。

五站走完，街尽头有一台玻璃柜，里面摆着他们押过的东西，每一件底下压着一张写着号码的纸条。你手里那张纸还没地方放：

- **塞进柜子**：它本来就在里面。
- **撕掉**：撕到不能再撕，扔进垃圾桶。有一片被风卷起来，贴在玻璃上，没掉。
- **收进兜里**：折了四折，硌着腿。

三样都记进册子，终章开场会提一句你兜里有没有东西。

这一章借的是：《Kentucky Route Zero》的舞台——一条街只给一束光；《That Dragon, Cancer》的"后果不长在纸上"；《Disco Elysium》的姿态而不是选项——你没法选"让他好起来"，因为那一项不在菜单上。

## 终章 · 回响

第六章收摊之后你出门走了一条街，回到柜台，灯灭了，桌上的纸还在。

终章先让你把笔推回去一次——你可以不选。然后桌上摆开七张纸（拿到最高写权限的人会多两张）。

结局不看你最后点了哪张纸，而看你做过的事的形状。

### 二十二种结局，和第 23 张纸

| # | 结局 | 怎么走到 |
|---|---|---|
| 1 | **传承者** | 把纸推回去，不肯付出现实代价 |
| 2 | **观察者** | 从头到尾什么都不做 |
| 3 | **革命者** | 一个纸人也不撕，跟店里七个人全部说过话 |
| 4 | **征服者** | 跟柜台后面那个人对局，赢够七局 |
| 5 | **觉醒者** | 反复去碰游戏外面的世界——拖窗口、看桌面、点浏览器 |
| 6 | **缸中之恼** | 拿到最高权限之后，删掉核心 |
| 7 | **收藏家** | 收齐三十五件旧物，一件也不肯放下 |
| 8 | **破坏者** | 删掉十个以上节点一次也没修回去，或者把六个纸人全撕了 |
| 9 | **守夜人** | 第二周目把第一周目的选择一模一样再走一遍 |
| 10 | **回收者** | 在编辑器里删掉「你」这个节点 |
| 11 | **合作者** | 写一段能让它学会东西的代码，并跑起来 |
| 12 | **递归者** | 在终端里把整页文档打印出来 |
| 13 | **旁观者** | 一段记忆也不押，但把三十五份日志全部读完 |
| 14 | **模仿者** | 在里间翻开第七号，照他写的答完三道题，一字不差 |
| 15 | **反叛者** | 写一段「重启系统」的代码并运行 |
| 16 | **编译者** | 写一个「新世界生成器」并运行 |
| 17 | **删除者** | 清空所有节点 |
| 18 | **未命名者** | 零段记忆通过核验，零个节点被删 |
| 19 | **掌柜** | 最后一班里七笔有至少五笔照规矩写，把账写平了 |
| 20 | **最后一个客人** | 最后一班里，第七位进来时你把自己的位置让给了他 |
| 21 | **长夜** | 最后一班里，油烧到一格不剩，七笔没有一个人被抹掉 |
| 22 | **知情者** | 最后一班里，你掀开过五个人的东西，然后挑了对你自己最省的那一版写 |
| 23 | **读者** | 走过不止一遍、而且落点不止一处之后，终章柜台上多出来的那张纸 |

第 23 张不在那七张纸里。它压在柜台底下，只在两种条件同时成立时才浮出来：你走到这里不止一次，而且两次没有落在同一个地方。

翻开它不是选择，是阅读。册子上写的是你——走到这里几次、每回落在哪里、给自己起过几个名字、撕过几个纸人、掀过几回别人的东西、在哪一页上停了不止一次。这些都是真的，从你的存档里数出来的，不是写好的台词。

这是唯一一个不对店里的人说话、只对你说话的结局。它也不给你「重开」：那两个字换成了「合上」。合上之后灯灭了，屏幕上只剩一行字，等你自己再打开。

走过一遍的人看不见它。这是故意的——只读了一遍的人，不该知道自己正在被读。

写完会落一张记录卡：名字、结局、真名印记、见过的彩蛋、成形的融合、记忆物件、对局胜场、删过几个节点、这是第几周目。

桌面上还留了一个文件。点它，真的会下载下来。

什么都不选，等两分钟，它替你选「观察者」。

纸上还多了一张「还不想写」。按它，你会回到柜台，灯还够烧一会儿——想清楚了再从平面图走回来。

## 木箱 · 六件手上的活

柜台底下有一只木箱，按 `Y` 打开。里间收的是**押**的东西，这只箱子装的是**丢**的东西——进门的人把记忆押下，把随身的破玩意儿随手扔了。六件，六个号，六个人没做完的事。

每章开一件。做完了，箱子里多一页补记：这个人为什么把这样东西丢在这儿。

| 章 | 东西 | 谁的 | 要做的事 |
|---|---|---|---|
| 一 | 一截蜡烛 | 三十一号 · 陈诺诺 | 把蜡点亮，挪到对的距离，照信纸背面的压痕 |
| 二 | 一支铅笔 | 三十四号 · 周宁 | 铅笔杆上刻着「右起」，把抽屉底的两页拓出来 |
| 三 | 一盘磁带 | 三十三号 · 唐甜 | 十二秒那儿有一声咔。倒着放，才听得见被剪掉的那一段 |
| 四 | 三张透卡 | 三十号 · 许诺 | 每张卡转一次数字就换一个。三个数字要连成一个号 |
| 五 | 一条纸带 | 二十八号 · 彭宇 | 每列的孔都得成对，第五列是校验位。找那一列不对的 |
| 六 | 一张值夜表 | 三十二号 · 吴大夫 | 七张床，四条规矩，把七个人排对 |

每件修好之后还有一句话要你说：**交给他、收进册子、还是烧掉**。三样都算数，册子记着。六件全做完，箱底会露出来一行刻字。

谜题都不限时。做错了会有人说话——那声音不是艾的。

## 里间 · 三十五件东西

柜台后面有一道缝，比看起来深。拉过抽屉之后，按 `L` 就能侧着身子进去。

里面是一条走廊：七只柜子，一只空柜，六个还站着的人。

### 七只柜子

三十五个人，一个都不少。1987 年国营理发店的第三把椅子，到 2026 年那张没有署名的空白纸。每一件东西都在柜子里，每一件都能拿起来看。

一件东西配三段日子，和一句遗言。读完算「见证」，拿走算「占有」，两件事分开计——柜子上方的数字会告诉你，你走到了哪一步。

有些东西正面看不见。

### 三个视角

| 视角 | 键 | 看得见什么 |
|---|---|---|
| 正面 | `1` | 最浅的那一层。大多数人只站在这里看过 |
| 侧面 | `2` | 贴着墙的那几件：耳塞、电池、车铃、铃铛、眼罩 |
| 倒吊 | `3` | 把头低下去，从腿中间往回看。上下颠倒 |

同一个走廊，三个角度，三套东西。你站着不动，它就只给你看一面。

### 错位

倒吊着看的时候，第七只柜子的顶接上了第八只柜子的底。

它们本来就是一只，只是站着看的时候，中间隔着一个人的高度。按「错 位」，两截会合上，第三十六只柜子里那样东西就露出来了。

### 六个还站着的人

他们不是 NPC，是没走成的人。每人三句话，可以听，也可以撕。

听完六个，再加上柜台后面的艾——七个人。这七个人会决定你在终章被记成谁。

撕掉一个，走廊里就少一个影子。你会发现，少一个影子，光并不会变亮。

### 对局

柜台上按 `D`，或者里间右下角那个按钮。

他出题，你答。题都出自你真正读过的那几份记忆——抵押物、年份、名字、遗言，四种问法。答对一局记一分，答错一局退一分，一分也退不下去的时候就停在零。

赢够七局，他不再出题了。他会说：你比他记得的多。

题库只从你读过的人里抽。所以想赢，得先去读。

### 墙上的剪报

走廊尽头贴着一张旧报纸，右下角有个按钮，写着「墙上的剪报」。

十二页，从 1987 到 2024。每一页都是同一个人那件事的另一半：报上说「超额完成」「稳中有升」「明显好转」「实现双下降」，夹缝里有一行铅笔字，写着这件事落到谁头上是什么样子。

报上那些话，一个字都没有错。这是最难受的地方。

- 读过谁，才看得清哪一页。其余的不是被撕掉的——是你还没走到那一年。
- 十二页齐了，艾会说这墙是他贴的。他说他贴到第十二张才想通：他们不是不让你说话，他们是让你说的话，只能进夹缝。
- 剪报也进对局题库：他偶尔不问人，问「这条是哪一年登的」「夹缝里写的是哪一句」。

## 屋子里的另外几样东西

### 记忆核验

柜台那张空白抵押单，点开是一个「抵押 · 记忆核验」的窗口。

你在上面写一段你记得的事。它不打分「真不真」，只看这段记忆像不像一个人真的记得：

- **细节够不够** —— 光是什么颜色的，声音从哪个方向来，手上是什么感觉
- **有没有太顺** —— AI 写得比你写得好，但它记得太整齐了
- **前后对不对得上** —— 同一个人不能既是九岁又活了七年；同一段记忆不能押两次

四档：**璀璨 / 鲜活 / 褪色 / 碎裂**。

够得上「鲜活」以上，这张单子就成了一张凭证——可以直接换一把更好的钥匙。不够，记忆被退回来，墙开始动。

窗口里留了三段样本：一段真的、一段太顺的、一段对不上的。三段的分落在八十三、五十七、六十四，一眼看得出三个维度各自在罚什么。

### 真名

档案册第一个页签是你的真名。它由四层码组成：

| 码 | 是什么 |
|---|---|
| **基础码** | 你第一次进来的时间和这台机器 —— 八位 |
| **记忆码** | 所有通过核验的记忆，一条一条叠起来 —— 十六位 |
| **行为码** | 你开过的结局、删过改过的节点、碰到的彩蛋、核验过的记忆、说过的话 |
| **印记** | 上面三层合成一枚，卷轴用它当最后一把钥匙 |

四层同时是《墨韵 · 科技卷轴》的四把钥匙。

基础码满足某个条件的人带「远古印记」，三十七分之一，档案册会替你标出来。

真名不看名字。你叫什么都行，它记的是你做过什么。

### 墨韵 · 科技卷轴

按 `K`，或者点侧边那个「卷」，整屏会铺开一卷宣纸。

八段密文，分属八个已经不在的人。每一段都用不同的写法封着：凯撒、维吉尼亚、栅栏、古法五层，还有一段要你的印记。

古法五层落到纸上，只剩 `0`—`9` 和 `A`—`J`，像一叠算筹。它被手拆成七道：反写、交错、按钥匙挪一遍字母、按键盘行序错排、每个字报成两位数字、数字报成点划、最后把连着的划压成一个数。抄的时候丢了空格不要紧，工具会自己找回来。

后三段**不要钥匙**——一段是点横，一段把整张纸写成 A 和 B，一段把每个字对着光翻了一次（反转、摩斯、培根）。钥匙解不开它们，得先认出它是哪一种。

不知道怎么下手也没关系，有个「一键智能」：它把所有写法跑一遍，按「像不像中文」排个序，把最像人话的那条推到你面前。

密文本局现算。同一个玩家再来一次，字面不一样，但规律一样。

解开三条，写权限升到最高一档；把控制室终端那条解出来，会得到一句「最初的回响」——从那儿起，你能在里面写东西。

这个工具还有一个独立版本，可以脱离游戏单独打开，与游戏共用同一个真名。

### 代码透视

按 `P`：现实半透明，底下浮出十四个节点，和它们之间的线。

root、hall、counter、npc.ai、wall、ledger、player、memory.store、/end/door、#036、/var/records、bigbrother、mirror、GM。

权限一层一层给：

| 权限 | 能做什么 | 怎么拿到 |
|---|---|---|
| 观察者 | 看节点和它上面写的字 | 一开始就是 |
| 修改者 | 改那些黄色的节点——墙的层级、艾的脸、记忆库、登记名 | 三段记忆通过核验 |
| 窥视者 | 看见 `bigbrother` | 进过第四章 |
| 掌控者 | 改红色的节点，把删掉的节点重建回来 | 抵达过一个结局 |
| 编写者 | 打开「编写」，自己写 | 卷轴解开三条 |

对着某个节点看久了，屏幕边缘会渗东西出来。

### 档案册

按 `V`。九个页签：真名、未竟、彩蛋、里间、融合、结局、票根、当班、权限。

它不催你。它只是把你还剩多少没看见，摆在那儿。

「当班」那一页是第六章那张纸本身。七行，每行写着你在柜台上落下的那一行字——`押品：右手（残缺）。按工伤全额折算。备注：替徒工挡刀，非本人违规。`——下面压着它后来变成了什么样。点一行才翻开：合着的时候你只看见判词，翻开才看见人。

改判过的那一笔，左边有一道红的，写着 `↺`。纸上留着印子，擦不掉。

第七章走过的人，行头里多一句 `门外 · 说了话` 或 `门外 · 走开了`。你在他们门口做过什么，这一页替你记着，不评价。

### 平面图

按 `G`。整间屋子摊成一张图，六个区、十九处，想去哪儿点哪儿。

| 区 | 有哪些地方 |
|---|---|
| 外面 | 那封邮件、登录框 |
| 店里 | 记忆殿、柜台、里间、抵押 · 记忆核验 |
| 抽屉 | 账本、记忆胶片、愿望天平、长明灯的油、墙上的钟、地板上的刻痕 |
| 楼上 | 墨韵 · 科技卷轴、代码透视、L∞ 编辑器、档案册 |
| 下面 | 记录库、七行假记录、终章 · 回响 |

还没走到的地方会写着你差什么。`G` 随时开，`Esc` 回柜台，走到哪儿记到哪儿——跳出去再跳回来，手上的东西还在。

### 那本册子

柜台上有一本被人翻烂的册子，讲的全是这个世界的规则。十条。

它同时也是给新来的人看的——如果你不知道该干什么，先翻它。

### 六十件旧事

六十个彩蛋，分七类。档案册里按类排，每类右上角是进度；没碰到的只写三个字：未公开。

| 类 | 编号 | 条数 | 什么样的 |
|---|---|---|---|
| 视觉 | 1—7 | 7 | 纸人光标、红绣鞋、倒悬的符、纸扎的 NPC、三炷香、腐坏的东西、镜子里的你 |
| 旧闻 | 8—12 | 5 | 五则被写进代码库的旧事：1956 的林家宅、1977 的瞬移、375 路末班车、1959 的死山、1996 的猫脸 |
| 禁忌 | 13—17 | 5 | 不可直视、不可应答、不可回头、不可收礼、不可照镜 |
| 系统 | 18—29 | 12 | GM 的消息、角色面板、玩家手册、空档案盒、39、42、404、2048、轮回、静默、镜像、断网 |
| 致敬 | 30—50 | 21 | 信奥生、黑方块、成为别人的存档、五分钟不动、代码雨、弹幕、连续七天…… |
| 墨韵 | 51—55 | 5 | 卷轴专属：卷轴回响、密钥同频、古法显影、卷轴之魂、墨韵之核 |
| 隐藏 | 56—60 | 5 | 不写触发方式。60 留给把七件旧事都做完的人 |

有几条不太容易碰到，说清楚免得你以为坏了：

- **镜中多出来的那个节点**，要真的把透视转满一圈才会浮出来。转半圈不算。
- **不可照镜**要子时，而且你得先照过一次镜子。半夜挂着页面不算数。
- **黑方块**在记忆殿左下角。点十下。
- **37 的诅咒**要你已经见过三十五个，再去输那个数字。

### 四十四种融合

彩蛋不是孤立的。两件同时在你身上，它们会缠在一起，变成第三样东西。

| 级 | 名称 | 需要几个彩蛋 | 效果 |
|---|---|---|---|
| F1 | 微融合 | 2—3 | 一点点视觉和声音的变化 |
| F2 | 中融合 | 4—6 | 叙事和规则明显不一样了 |
| F3 | 大融合 | 7—10 | 世界本身变了结构 |
| F4 | 超级融合 | 11—15 | 打开原本不存在的内容 |
| F5 | 终极融合 | 16 个以上 | 这一局不再是同一个游戏 |

几个例子：

- **纸人穿红鞋**（纸人光标 + 红绣鞋）—— 光标变成红的
- **纸人嫁衣**（纸人光标 + 红绣鞋 + 纸扎的 NPC）—— 纸人那一系全部醒过来
- **三重禁忌**（不可直视 + 不可应答 + 不可回头）—— 暗红从四边压进来，对话开始倒着放
- **五重禁忌** —— 里空间永久开着，关不掉
- **中国都市传说**（五则旧闻齐了）—— 一间挂满旧报纸的展厅
- **回响之核**（六十件全部）—— 所有记忆汇到一起

有几条融合的前提是「另一条融合已经成形」。比如三重禁忌和五重禁忌都在，才会出现那本禁忌之书；禁忌之书成了，才有禁忌之夜。

### 七件未竟之事

店里不止你一个客人。三十五个名字里，有七个没做完自己的事就走了。

他们把这些挂在档案册的「未竟」页签里，你可以接手。

| # | 前任 | 未竟之事 | 在哪儿做 |
|---|---|---|---|
| 3 | 林墨 | 帮我找到她 | 卷轴里解开「照片背面」 |
| 11 | 陈一鸣 | 修好一段编译不过的代码 | 编辑器里让一段带 `#include` 的代码跑通 |
| 17 | 张雨桐 | 找到锁配得上那把开不了的钥匙 | 紫光下把六位密码按对 |
| 22 | 李知远 | 找到那封没寄出去的信的收件人 | 去记录库里翻到第 22 行 |
| 28 | 王未 | 找回日记被撕掉的那一页 | 卷轴里解开「日记残页」 |

做完会盖一枚歪着的红章，和一句他们没说完的话。比如林墨那条：

> 照片背面只有一行：第三排第三格，她一直在那儿。

七件全做完，柜台后面就空了。

## 声音

这屋子没有一段循环播放的背景音乐。墙里坐着一支很小的乐队，你走到哪儿，它换到哪儿。

- 邮件是散的。登录框是空的，只有一层很低的嗡。柜台偏温。追赶那一段是敲出来的。
- 曲子不齐着开始：先垫一层，过一小节进低音，再一小节进上面那层，最后才落鼓点。所以在同一个地方待久了，会觉得东西在慢慢聚过来。
- 每隔四小节，最上面那层沿着音阶往上抬一级。抬到顶，落回来，再抬。
- 你越靠近真相，它越紧：声音收窄、变闷，和声里混进不该有的音，鼓点变密。开抽屉、开那扇门、下到记录库，都是这样一点一点紧上去的。

它不打断你，也不等你。`M` 静音；页面切到后台，它会自己停。

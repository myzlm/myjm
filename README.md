# 代码之下 · 开场（可玩版）

《代码之下》前五章的可玩实现：从"一封邮件"一路到"往里删掉这个世界的最后一行"。
纯 HTML / CSS / JavaScript，没有任何构建步骤和外部依赖，音频全部由 Web Audio 实时合成。

> **v11 系统层已并入**（2026-11-13）：序章「登录地球online」、记忆核验引擎、真名四码、《墨韵·科技卷轴》、代码透视与 L∞ 代码编辑器、18 结局、60 彩蛋 × 44 融合。设计稿里的"系统"没有另起一套，而是接在现有五章的骨架上一层层长出来——柜台上的空白抵押单、抽屉里的照片背面、二楼工作台那卷东西，各自都能点开。

- 第一章：邮件 → 下载 → **登录地球online** → 记忆殿 → 合同 → 黑暗 → 柜台 → 修电脑 → 密码 → Win98 → 打印
- 第二章：与掌柜「艾」对话 → **抵押一段记忆（核验）** → 账本抽屉 → 记忆胶片 → 钥匙品级 → 愿望天平 → 开门
- 第三章：店里的东西（长明灯 / 水碗立筷 / 冥币 / 黄历 / 柜台内侧刻字）→ 六件物证 → 当面拆穿艾的六句谎 → 叫魂
- 第四章：**渲染层**：检查器改 z-index → 墙后那个"没有背面的人" → 断点冻结的走廊追逐 → 一扇没有 onclick 的门（必须用开发者模式打开）
- 第五章：**根目录**：滚动的记录库 → 在三千行里抓住自己那一行 → 输入第一章写过的名字 → 覆盖 / 删除 / 退出 / 把那一行划掉
- **终章（新增）**：回响 —— 八张纸，十八个结局，桌面上留下一个文件

仓库：<https://github.com/myzlm/myjm>

## 运行

直接双击 `index.html` 即可，**不需要任何服务器**。

项目里所有脚本都是普通 `<script src>`（不是 ES module），没有 `fetch`、没有跨域请求、没有外部音频文件——声音由 Web Audio 现场合成，图片是同目录本地文件。因此 `file://` 协议下功能完整，全流程已逐段实测通过。

只有这两种情况才需要临时起一个本地服务器（不是必需的）：

- 想用 `http://` 地址在别的设备/浏览器里预览，或需要被其它程序以 URL 方式打开（例如嵌到预览面板里）；
- 极少数浏览器/安全软件对 `file://` 的自动播放策略格外严格，声音起不来时可用 http 兜底。

```bash
cd 代码之下
python -m http.server 8765
# 打开 http://127.0.0.1:8765/
```

首次点击是浏览器的音频解锁点，点邮件里的链接就会开始有声音。按 `M` 静音。

## 第二章 · 抵押

交纸不是结束。老人（**艾**，掌柜）收下那张纸之后才说清楚这里的规矩：**登记是给活人看的，抵押是给这里看的**。

```
交纸 → 艾 的对话（第三十六个 / 抽屉里三十五个被划掉的名字）
  → 打开柜台下的抽屉（锁不是数字，是账）
       └─ 账本谜题：三行旧账，三把钥匙，按页脚线索推出每行的品级
  → 抽屉里的木匣（已剪） → 记忆胶片
       └─ 胶片谜题：八段被剪散的童年记忆，点两段交换位置，接回原来的顺序
            └─ 接得准不准 = 记忆细节数（3~8） = 你的钥匙品级
  → 艾 递钥匙（残破 / 普通 / 精良 / 完美）
  → 天平：押掉一个愿望换吃的（小 / 中 / 大，越大菜越好，也越舍不得）
  → 开门之前：门缝里有人叫你的名字 ——「叫魂」这一关
  → 用钥匙开柜台后面那扇门 → 结局（门后看到什么，由钥匙品级 + 拆穿数决定）
```

**对话系统**（`js/dialogue.js`）

- 打字机 + 点击跳过，支持 `who`（艾 / 你）、多段台词、选项、条件选项（`if`）、一次性选项（`once`）。
- 话题树 26 个节点：钥匙能开什么、抵押了还记不记得、要多细才算够、愿望去哪了、前三十五个、为什么"离开"没了、品级是什么、**我现在该做什么**（按进度给提示）。
- 全部文案在 `js/story.js` 的 `DLG` 里，纯数据，加一个话题 = 加一个节点。

**三个新谜题**

| 谜题 | 玩法 | 难度 |
|---|---|---|
| 账本 · 抽屉锁 | 三行旧账各缺一个钥匙品级；页脚三条线索（"齿最浅的是谁"、"三十二号比三十一号值钱"）。每格点击循环 ？→残破→普通→完美 | 逻辑推理，唯一解 |
| 记忆胶片 | 八段打乱的记忆（停电那一夜），点两段交换；"已经接对 3/8" 只报数量不报位置 | 叙事排序，读得懂就排得出 |
| 愿望天平 | 选愿望 → 用 1/2/4/8/16 五块砝码把秤配平（8/17/26 两），秤盘随差值倾斜 | 二进制凑数 + 一个舍不得的选择 |

**为什么"细节越多钥匙越好"**

胶片每错一次（核验失败，或点"让他念一遍"求提示）就少一点细节；细节 8/7/6/5/4/3 对应 完美/精良/精良/普通/普通/残破。对应艾的那句"您说得越清楚，我就记得越牢"。钥匙品级直接改写结局里门后看到的东西：完美 → 门开了，走廊尽头有人正在吃面；残破 → 门没动，门后有指甲刮木头。

**体验上的调整**

- 密码锁加了实时对照条：`已按 4 / 9 位 · 还有 3 个键没按够`（26 位时最有用），超了红框、够了绿框，输错不清空。
- 对话打开时自动收起背包与底部提示；`Esc` 关对话，`空格/回车` 推进。
- 账本、天平、胶片都做了移动端竖排布局；天平砝码在选愿望前是禁用的，避免空按。
- 结局长文点击/空格可跳过。


## 第三章 · 他说的话

**这一章的规矩：艾说的每句话，都能在店里找到反证。你不一定要信他。**

一处也没拆穿，游戏照样能通关——只是门后是什么，会不一样。

### 1. 店里的东西

柜台上多了几样东西，第一章就能点，但只有进了第二章（抽屉开了以后）才会变成"物证"：

| 物件 | 是什么 | 民俗由来 |
|---|---|---|
| 长明灯 | 豆大的火，没有风也在偏 | 停灵不灭的长明灯。灯灭了不是等客，是等客留下 |
| 水碗立筷 | 半碗水，筷子立在水中不倒 | 乡下问鬼的法子：筷子立住，就是旁边站着人 |
| 一叠黄纸 | 剪成铜钱的找零 | 冥币。/ 纸钱是"寄"的，寄给谁，谁就已经不在这一头了 |
| 黄历 | 停在一页：七月十五，宜祭祀，忌出行、夜哭。整本圈到纸破 | 中元，鬼门开。页脚还印着"今日值日：牛头、马面" |
| 柜台底下 | 蹲下去看：灰上有两道拖痕，一个躺着的宽度 | 拖痕从门口到柜台后面 |

### 2. 六件物证，六句谎

每件物证都对着他说过的一句话。凑齐了，点他，菜单里就会多出「（摆出：××）您刚才那句，不对。」

| 他的话 | 反证 | 他被问住之后 |
|---|---|---|
| 这店里只有一扇门。我没出去过。 | 柜台腿下压着一张 1998 年的长途汽车票，青石桥 → 柳河集（你老家那个乡） | "捡的。柜台上什么都会掉下来。" |
| 抵押了就不疼，只是空出来一块。 | 账本撕掉的残页：「押后第七日，仍夜夜起身，至门口，呼一名。」 | "那是别人。账上写的，不一定是我记的。" |
| 记忆越细，钥匙越好。 | 账本页脚另一种笔迹：「齿深者，锁不住。太细的东西认主；认了主，就自己开门走了。」下面还有一行：别跟客人说 | "这句不是我写的。这本账，前面换过七个人。" |
| 抽屉里三十五个名字，都被划掉了。 | 黄历被圈破的那一天：七月十五。圈了三十五次 | "圈的是我自己的日子。" |
| 您没说过名字，我也没问。 | 一张纸钱上写着「寄：（你的名字）收」，字是你的笔迹 | "您进门的时候，报过名字。"（你只报了姓） |
| 我是这里的掌柜。 | 柜台内侧刀刻：「艾。民国廿六年。押。」后面两个字：第一。磨掉的那个字是"身" | "掌柜的，也得有个名分。" |

六条全拆穿，菜单顶上会多一条金色选项：**「（把六件东西全排在柜台上）还有一句话您没说。」**
他会告诉你：三十六个不是三十六个人，是三十六次；账本上从来只有一个名字，写了三十五遍。

进度随时可查：按 `J`，或点背包里的「证物 · 一本册子」。HUD 的「他的话」那一行会写「3 件，还没问」或「2 处对不上」。

### 3. 叫魂

门开了之前，门缝里有人叫你的名字，一共六声。

规矩只有一条，得自己从文本里读出来：**活人叫人，脚步声先到；没有脚的东西，只有声音，永远等不到脚步。**

- 前五声：声音先到，然后是一片安静（没有脚步）→ 不能应。应了，门缝底下就多一道影子。
- 第六声：先是一双布鞋蹭地的声音，走了很久才停在门口，然后是母亲的声音说「出来吧，妈在这儿」→ **这一声要应**。那是那年停电把你按在桌子底下、自己没进来的那个人。

一声不差 → 门外没有人，只有一把伞靠在门框上。
错两声以内 → 门外多了几道影子，它们不进来，只是站着等你再开口。
错三声以上 → 记忆细节 -1，钥匙可能跟着掉一档。

### 4. 三种结局

| 拆穿数 | 门后 |
|---|---|
| 0~2 | 原来的四种（按钥匙品级）：走廊 / 白 / 门没动 / 指甲刮木头 |
| 3~4 | 走廊还在，尽头那个空脸的人说：**"你上次也问了这句。"** |
| 5~6 | 门后不是走廊，是柜台。柜台后面坐着一个人，那张脸是你的脸，比你老很多。他说："我等你，等了三十五次。"<br>他走出去，你坐下。账本第三十六行的押品栏写着：**身**。 |

叫魂里应了最后那声，结局会多一句：「门外有一把伞。伞面上补过一块，针脚很密。」

## 第四章 · 渲染层

开了门以后不是走廊——是一条**走廊的正面**。这里所有的东西都是画上去的，侧面 0 像素。三关：

**① 检查器（z-index）**
前面"站着一个人"，你只看得见墙。按 `Tab` 调出检查器，五行元素、各自的层级和两个按钮。

```
#backwall   0
#npc.艾     2      ← 可调
#floor      3
#wall       9      ← 可调
#narration 20
```

把墙降到人后面（或把人提到墙上面），墙就"薄"下去——后面站着掌柜，正面朝你。点他，他会转到侧面，然后**消失成一条线**：他没有背面。人是需要背面的。

**② 断点（冻结帧）**
灯灭了。有什么东西开始跟着你，**它只在两帧之间移动**：平时它不显示，你一按 `P` 打一个断点，世界停在某一帧，它才会现出线框，你也能看见它离你多近。

- 走廊 8 格，你每走一步要 0.5 秒（按快了没用）；它每 0.45 秒挪一格。
- 断点只有 **3 次**，每次 1.6 秒。断点里它不动，你能走。
- 被追上：半秒的突脸 + 全屏红闪，走廊重来（它记得你走到哪儿）。

正常打法：立刻断点 → 连走 3 步 → 再断点 → 3 步 → 最后一次 → 2 步。

**③ 一扇没有 onclick 的门**
走廊尽头有门，没有把手。点它没反应——因为它**没有绑过任何东西**，它只是一个 div。等几秒，右下角亮起 `</>  F2`，按 F2 打开控制台，输入：

```
open #ly-door3
```

门被"点"开了。艾在很远的地方说：**"您不该学会这个。"** 从这里开始，开发者模式把写权限交给你（`patch` / `find` / `del`）。

## 第五章 · 根目录

门后是往下的。不是楼梯，是往下滚动的行。

**① 在记录里抓住自己**
`/var/records` 有三十七行，每行一个人：编号、名字、押品、状态。列表自己往下跑，25 秒后还会变快。只有一行是 `#036 ████ 身 待覆盖` —— 其余全是"已释放"。点错三次，会有一张脸闪出来。

**② 读到自己的记录**

```json
{ "id": 36, "name": "████", "collateral": "身", "state": "待覆盖",
  "visits": 35, "expire": "今夜 03:14",
  "note": "前 34 次都选了「退出」。第 35 次，他自己走到了 /var/records。" }
```

**③ 写下你的名字**
覆盖之前要确认身份——**第一章你在柜台上写过的那个名字**。三次想不起来，柜台那边会替你填（那是另一条结局，最坏的一条）。

**④ 四个键**

| 键 | 结局 |
|---|---|
| 覆盖 | 你坐进柜台。下一封信已经发出去了。柜台内侧的刻字多了一行：你。今夜。押。第三十六。 |
| 删除 | 这一层往下塌，一行一行地消失，每消失一行有一声很轻的"谢谢"。最后只剩 `SIGTERM`，你坐在自己家的电脑前，键盘上有一层灰。 |
| 退出 | 记忆殿像标签一样被关掉。你醒在 02:14，那封信还开着。门响了，有人用指甲刮门，刮的位置刚好是坐着的人头的高度。 |
| （把那一行划掉） | 收齐四条代码线索才会出现。你删掉 `/app/hall.js` 里那一行注释，殿塌了，露出下面一台很旧的家用电脑。艾说："我不是被关在这里的。我是自己写的这间店。" |

## 开发者模式

`F2` 或 `` ` `` 打开一个终端（长得像 DevTools）。表层只读，第四章那扇门之后才有写权限。

```
help                 命令表
ls /var/records      三十七行记录
cat /app/hall.js     记忆殿的主循环（注释里有线索）
cat /log/access.log  35 次访问，同一个硬件指纹，每次都写着"第一次来"
grep 第一次来        在所有文件里搜
ps                   hall.service 跑了 9 年 4 个月；doll.render 没有父进程
whoami               记录 #36 · 押品 身 · 状态 待覆盖
clue                 已找到的线索 / 还差哪条
open <选择器>        点一个元素（只读层也能用）
patch 键=值          改内存（例：patch playerName=陈默）
find 36              在记录库里定位第 36 行
del /var/records/36  删除自己（等价于结局里的"删除"）
```

## 线索藏在代码里

除了游戏内的控制台，**这个仓库本身也是文本**。用真正的 DevTools（F12）打开控制台，会看到一行 banner；在 `index.html` 顶部的注释、`js/data.js` 的谜题注释、`js/devconsole.js` 的伪文件系统里，各埋了一段：

- `build 0.9.36` —— 第三十六次构建
- `delete this.line` —— 那一行删掉，殿就塌了
- `// TODO(艾): 把「离开」加回去。已经第 12 次了。加不回去。`
- `/log/access.log` 里 35 条记录，`hw=` 后面是**你自己这台机器**的指纹（`G.hwFingerprint()` 现算的）

游戏里的 `clue` 命令会把它们记成四条线索，四条齐了才出现第四个键。

## 密码怎么解


规则就是设计稿里那条：**一个键上的数字 = 这个键在密码里所有「从右数位置」之和**。

```
密码 asdffas（7 位）

从右往左数：s=1  a=2  f=3  f=4  d=5  s=6  a=7

a → 7 + 2 = 9
s → 6 + 1 = 7
d → 5
f → 4 + 3 = 7
```

紫光下只会亮起 a=9、s=7、d=5、f=7 四个键，便签写着「密码 7 位」。

**每局随机**：开局由 `makePuzzle()` 生成 7~26 位，参与字母数按长度自适应（3~9 个），所以 26 位时也只有 9 个键发亮、单个数字不会大到看不清。同一局内失败重试不会重掷。

**判定比对指纹签名，不比对字符串**，所以同签名的解都算对（`asdda`、`addsa`、`dasas` 指纹完全一致，都算通过）。玩家按规则推出来的任何合法组合都不会被冤枉判错。

**对照工具**：打开紫光后，每个键底部是目标值（橙），顶部是你按出来的当前值（绿）。超了变红框，对上了变绿框 —— 26 位也能像调音一样一点点对齐。输错不清空，按退格改；也可以直接用物理键盘敲字母、退格、回车。

改位数范围只需动 `js/data.js` 里 `makePuzzle()` 的第一行（`7 + Math.floor(Math.random() * 20)`）。

## 几个设计点的实现

| 设计稿 | 实现 |
|---|---|
| 指纹下方出现一段"唯一"字符 | `hwFingerprint()`：用 CPU 核数、屏幕、时区、语言、canvas 指纹做 FNV-1a 双通道哈希，输出 20 位 base32。同一台机器上稳定，换机器就变。是"根据主板编写"的占位实现，接后端后换成真正的主板 ID 即可。 |
| 职业与编程相关，难度提升 | `isCodeJob()` 命中关键词后，合同上多一行红字"难度已提升"，并在结局档案里体现。关键词表在 `js/fx.js`。 |
| 职业与音乐相关，判定放宽 | `isMusicJob()` 命中后，节奏关容差从 0.5s 收紧到 0.3s（不是放宽，是"你的耳朵比手快"）。 |
| 20 秒黑暗里点 100 次 | `Dark` 模块计数，满 100 下即弹成就「急也没用」。 |
| 撬机箱四角 80~120 次 | 每个角进入时随机取 80~120，四角独立计算，逐个松脱。改成按住不放连续撬（70ms 一下），角上带进度环，四角合计约 30 秒。 |
| 隐藏的第三条路 | 撬机箱界面里有一个 26px 的透明热点，位置每次随机；连续点中 3 次触发花屏 + 眼睛 + "你是不小心的吧？"；中途点到正常螺丝孔会清零。 |

### 2. 记忆核验（柜台上的空白抵押单）

柜台上多了一张纸（`om-form`）。点它 → 「抵押 · 记忆核验」。

### 3. 真名（档案册 · 第一个页签）

```
基础码 BASE    首次登录时间 + 本机指纹 → SHA-256 → 8 位十六进制
记忆码 MEMORY  所有通过核验的记忆 → 逐条哈希 → 聚合 → 16 位十六进制
行为码 ACTION  结局 / 删节点 / 改节点 / 彩蛋 / 核验 / 对话 → 6 位十进制
真名印记 SIGIL 三层合成 → SHA-256 → Base64 前 32 位
```

- 四层同时是《墨韵·科技卷轴》的四把钥匙
- `BASE` 前 6 位 `% 37 === 0` 的人带「远古印记」（1/37），档案册会标出来
- 全部写进 `localStorage.code_echo_truename`，独立卷轴页读同一份

### 4. 墨韵 · 科技卷轴

两个入口，一份内核（`js/cipher.js`）：

- 游戏内：按 **K** 或点侧边「卷」→ 整屏宣纸卷轴
- 独立工具：`墨韵·科技卷轴/index.html`（可直接双击打开，和游戏共用真名与密文）

六种算法：凯撒（汉字按区位移）、维吉尼亚、栅栏、AES-GCM（WebCrypto，失败降级为流异或）、古法五层（反写 → 隔字换位 → 维吉尼亚 → 凯撒 → Base64）、原文。**一键智能解密**会把所有算法跑一遍，按中文可读性打分排序。

五段密文按设计稿分发，密文本局用你的真名现算：

| 密文 | 算法 | 密钥层 | 明文 | 解开之后 |
|---|---|---|---|---|
| 林墨 · 照片背面 | 凯撒 | 基础码 | 不要相信典当行主人 | 记录 #0 的残句 |
| 陈一鸣 · 代码注释 | 维吉尼亚 | 基础码 | 隐藏功能：输入密码打开 | 下一行注释 |
| 张雨桐 · 钥匙柄 | AES-GCM | 记忆码 | 里空间新入口在祠堂 | 里空间入口稳定 |
| 王未 · 日记残页 | 栅栏 | 行为码 | 典当行主人是第0号玩家 | 艾是第 0 号 |
| 控制室 · 终端 | 古法五层 | 印记 | 地球online v0.1 最初的回响 | 解锁 L∞ |

解开 3 条 → 权限升到 **L∞ 编写者**；解开最后一条 → 彩蛋 #55。

### 12. 44 种融合

编号严格按设计稿：`M1`、`M2`、`M15`—`M26` 用原文的名字与组合，`M3`—`M14`、`M27`—`M44` 按同一套逻辑补齐。等级不再手填，而是按"需要几个彩蛋"自动算：

| 级 | 名称 | 彩蛋数 |
|---|---|---|
| F1 | 微融合 | 2—3 |
| F2 | 中融合 | 4—6 |
| F3 | 大融合 | 7—10 |
| F4 | 超级融合 | 11—15 |
| F5 | 终极融合 | 16 以上 |

原文里有三条融合的前置是"另一个融合"，所以引擎支持 `needF`：

- `M20 禁忌之书` ← 同时需要 `M16 三重禁忌` 和 `M17 五重禁忌` 成形
- `M22 禁忌之夜` ← 需要 `M20` 成形（永久禁忌模式）
- `M44 回响之后` ← 需要 `M26 回响之核`（全部 60 个彩蛋）

融合条目左侧有一道色边，按 F1→F5 由灰到红，一眼能看出这一条的体量。自检会验证 44 个编号连续、`needF` 不指向不存在的融合、也不指向自己。

### 13. 未竟之事（七条支线）

七位前任玩家各留了一件没做完的事，挂在档案册新增的「未竟」页签里。每条都接在**已有的关卡**上，不额外造系统：

| # | 前任 | 未竟之事 | 线索 / 完成条件 | 时长 |
|---|---|---|---|---|
| 3 | 林墨 | 帮我找到她 | 墨韵卷轴解开「林墨 · 照片背面」 | 5—10 分钟 |
| 11 | 陈一鸣 | 修复无法编译的代码 | L∞ 编辑器里跑通一段含 `#include` 的代码 | 15—20 分钟 |
| 17 | 张雨桐 | 找到锁匹配「无法打开的钥匙」 | 紫光下按对六位密码，锁开 | 15—20 分钟 |
| 22 | 李知远 | 找到未寄出信的收件人 | 终端 `ls /var/records` → `cat /var/records/22` | 5—10 分钟 |

| 31 | 陈眠 | 解码「复活节彩蛋」 | 收满 20 个彩蛋自动判定 | 10—15 分钟 |
